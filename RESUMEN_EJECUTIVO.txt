================================================================================
                         🔴 ERRORES QUE FUERON CORREGIDOS
================================================================================

1. ✅ Autenticación sin validación
   ANTES: Aceptaba passwords vacías o muy cortas
   AHORA: Valida email, password mínimo 6 caracteres

2. ✅ Tareas no se guardaban en Firebase
   ANTES: Marcaba como completada pero no sincronizaba
   AHORA: Se guardan automáticamente en tiempo real

3. ✅ structuredClone() incompatible
   ANTES: Fallaba en navegadores antiguos
   AHORA: Usa JSON.parse(JSON.stringify()) universal

4. ✅ Permitía crear tareas con fechas pasadas
   ANTES: Sin validación
   AHORA: input date con min=hoy

5. ✅ IDs duplicados en modo demo
   ANTES: crypto.randomUUID() generaba colisiones
   AHORA: Timestamp-based (task_1694291234567)

6. ✅ Memory leaks en listeners
   ANTES: onSnapshot nunca se limpiaba
   AHORA: Llama unsubscribe() antes de nuevos listeners

7. ✅ Configuración de Firestore incompleta
   ANTES: Sin rewrites para SPA routing
   AHORA: firebase.json con rewrites y rules

================================================================================
                         📞 SI ALGO FALLA
================================================================================

Problema: "Página en blanco"
→ Asegúrate que index.html está en la raíz

Problema: "Botones no responden"
→ Limpia cache (Ctrl+Shift+Supr en Chrome)

Problema: "Firebase no funciona"
→ Verifica proyecto "studysync-8bde3" esté activo

Problema: "Datos no se guardan"
→ Verifica reglas en firestore.rules

Problema: "Error al desplegar"
→ Instala Firebase CLI: npm install -g firebase-tools
